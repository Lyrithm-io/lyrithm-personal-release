# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for security problems.

Email: `security@lyrithm.io`

Include:

- affected image tag
- reproduction steps
- impact
- logs or screenshots with secrets removed

## Secrets

Never share these publicly:

- `license.json`
- `.env`
- `LYRITHM_MASTER_KEY`
- exchange API keys
- Telegram bot tokens
