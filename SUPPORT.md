# Support

## Private Support

Use email for anything involving private information:

- lost `license.json`
- refunds / billing
- license re-issue
- exchange API credentials
- screenshots containing balances or account identifiers

Email: `support@lyrithm.io`

## GitHub Issues

Use GitHub issues for reproducible technical bugs.

Please include:

- Lyrithm image tag, for example `1.0.3`
- operating system / VPS provider
- `docker compose -f docker-compose.personal.yml ps`
- relevant logs with secrets removed
- steps to reproduce

Never include:

- `license.json`
- `.env`
- exchange API keys
- Telegram bot token
- account balances you do not want public
